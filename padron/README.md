# Padrón Electoral - Ejercicio 2

Aplicación JavaFX para gestionar un padrón de votantes.

## Paquete institucional
`pe.edu.upeu`

## Funcionalidades solicitadas
- Alta de registros.
- Baja de registros.
- Consulta y búsqueda por folio, nombre o RFC.
- Modificación de registros.
- Datos: nombre completo, RFC, sección electoral, distrito y número de folio.

## Abrir en IntelliJ IDEA
1. Extraer el ZIP.
2. Abrir la carpeta `PadronElectoral` en IntelliJ IDEA.
3. Seleccionar JDK 21.
4. Esperar la carga de Maven.
5. Ejecutar `pe.edu.upeu.padron.Main`.
